01 / The purpose

Autonomy needs
visible boundaries.

Lodeward connects persistent memory and execution rules to the AI client. The MCP server handles queries; hooks act at workflow checkpoints. A learned lesson becomes guidance only after your approval.

02 / Workflow

Every decision is readable, even without 3D.

A gate before the command.

A hook checks command patterns before execution. Policy can allow, request confirmation or block. The detector is lexical: it cannot recognize every attack and does not replace a sandbox.

01 command received 02 policy checked 03 allow / confirm / block

Learning is not permission.

A recorded lesson enters quarantine. It should not guide the agent while awaiting review. Graph observations and approved lessons follow different paths.

01 lesson recorded 02 status: pending 03 use as a rule: not authorized

The rule is still yours.

You review the lesson and choose to approve or reject it. Change proposals have a separate cycle: approval, application and rollback. This page does not simulate human authorization.

01 owner review 02 approve or reject 03 decision recorded

Context that crosses sessions.

The MCP client queries the graph and approved lessons. Hooks deliver selected context; the compaction archive preserves material for retrieval. Better retrieval and lower usage remain hypotheses to measure.

01 MCP client query 02 memory selected 03 context with provenance

Explanatory demonstration. It does not execute commands, access your memory or approve lessons. Real integration depends on hooks installed in the client.

04 / Project status

The limits are
part of the work.

The engine runs and the lesson cycle has been demonstrated. General retrieval superiority, long-session savings and public readiness remain unproven.

  • 01Live security checks and the complete interface test suite.
  • 02Compaction A/B comparison and long-session evaluation.
  • 03Adversarial review and an audit of every claim.
  • 04Fourteen days of real usage before claiming daily readiness.
What earlier measurements did not demonstrate

Retrieval: 457 versus 456 in 470 queries, interpreted as a tie with BM25. Long sessions: ratio 1.2133 (95% CI 1.1039–1.3397), about 21% more usage in 45 pairs. Reduced context: 30 of 40 answers versus 40 of 40 with full context. Model tests used partial isolation. These are historical results, not rerun by this page.

Lodeward and the previous name

Lodeward continues the SynapseEngine project. Compatibility preserves the synapse alias and existing MCP contracts. A new identity does not mean every technical gap has been resolved.
